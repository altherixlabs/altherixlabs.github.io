Engineering practices

The unglamorous parts, done properly.

What goes into the production systems we run, as standard.

Security

  • Role-based access across production platforms
  • Hierarchy-scoped queries: users retrieve only their own data
  • Secrets kept out of code

Reliability

  • Logging, monitoring and alerting
  • Backups kept in good order
  • Scheduled work handled by background jobs

Delivery

  • CI/CD on Azure DevOps and GitHub Actions
  • Gated releases to production
  • Code review, with tests written alongside code

Governance

  • Audit trails on enterprise platforms
  • Exports stamped with scope, period and origin
  • Access enforced at the data layer, not only the UI
About

Global engineering. Rooted in the Nilgiris.

Altherix was founded in Ooty, high in the Nilgiris, and works from Coonoor in Tamil Nadu, India. It's an unusual place for an engineering company, and a deliberate one: a small, senior team with room to do careful work, away from the churn of a large delivery centre.

The work reaches well beyond the hills. Platforms we built run in production on Azure in the UK for a global organisation, alongside systems for manufacturers, clinics, education, logistics and finance teams in India.

One conviction hasn't changed: your existing software is the backbone of your business, and it usually deserves improving before it deserves replacing.

FAQ

Common questions.

01

What does Altherix do?

Altherix is a software engineering company. We build custom software and enterprise applications, modernize legacy systems, add AI and process automation, and integrate ERP, accounting and payment systems. We also run the CI/CD pipelines and cloud infrastructure behind them.

02

Which technologies do you work with?

Mainly .NET and ASP.NET Core, Java with Spring Boot, PHP with Laravel, Python with Django, and Node.js; React, Angular and React Native on the front end; SQL Server, MySQL, PostgreSQL and MongoDB; and Azure and AWS, with Azure DevOps and GitHub Actions for delivery.

03

Do you work with clients in the UK and outside India?

Yes. Platforms we built run in production on Azure in the UK for a global organisation, alongside systems for clients in India.

04

How does an engagement start?

With a conversation with an engineer. Email contact@altherix.in or use the contact form to describe your system and the outcome you need. We agree a scope together before any build work begins.

05

Where is Altherix based?

Our office is in Coonoor, in the Nilgiris district of Tamil Nadu, India. Altherix was founded in nearby Ooty.
